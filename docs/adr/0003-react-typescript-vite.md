# ADR-0003: React + TypeScript (Vite) frontend

**Status:** Accepted (given — HANDOVER §2)

**Decision.** React 19, TypeScript 5.9 (strict; TS 6 waits for openapi-typescript support), Vite 8, React Router 8, an SPA built into static files served by FastAPI in production. No SSR / Next.js. A local SPA needs no server rendering.
